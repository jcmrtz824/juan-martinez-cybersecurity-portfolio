## Project Details

### Project 01 - Vulnerability Assessment

Demonstrates a junior cybersecurity consultant's vulnerability assessment workflow using a synthetic lab scenario. The project shows scan planning, finding review, risk rating, evidence documentation, remediation guidance, and professional reporting.

Key skills demonstrated:

- Vulnerability management
- CVSS v3.1 scoring
- Risk prioritization
- Technical evidence documentation
- Remediation planning
- Executive communication

### Project 02 - Threat Intelligence Report

Demonstrates public-source threat intelligence reporting for a critical vulnerability. The project shows research validation, risk rating, MITRE ATT&CK mapping, documented public indicators, detection opportunities, patch guidance, and business-focused recommendations.

Key skills demonstrated:

- Threat intelligence research
- CVE analysis
- Public-source validation
- MITRE ATT&CK mapping
- Detection and response recommendations
- Executive risk communication

## Project Standards

Every project should include:

- Clear portfolio demonstration disclaimer
- Defined scope and exclusions
- Professional executive summary
- Technical findings or analysis
- Risk rating methodology
- Evidence or screenshot placeholders
- References
- Revision history
- Quality checklist
- PDF export when complete
