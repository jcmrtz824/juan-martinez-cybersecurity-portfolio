# Contributing

## Purpose

This repository is a professional cybersecurity portfolio. Contributions, edits, or issues should improve clarity, accuracy, documentation quality, security hygiene, or portfolio presentation.

## Portfolio Demonstration Rules

All projects must follow this wording:

> This project is a Portfolio Demonstration. It is a synthetic case study created for a cybersecurity consulting portfolio. It does not represent paid client work, employment history, or testing performed for a real organization unless explicitly stated.

Use this wording when no live systems were tested:

> No live third-party systems were tested. No real client names, production IP addresses, credentials, proprietary data, or sensitive information are included.

## Contribution Standards

- Use clear Markdown.
- Follow the master style guide in `Templates/MASTER_STYLE_GUIDE.md`.
- Keep headings consistent.
- Use clean tables with short, scannable cells.
- Add references when using standards, frameworks, CVSS scores, or external research.
- Keep report language honest and evidence-based.
- Do not claim client work, employment, authorization, or credentials without proof.

## Security Standards

Do not contribute:

- Real credentials
- Private keys
- API tokens
- Client names
- Proprietary data
- Production IP addresses tied to a real organization
- Sensitive screenshots
- Unauthorized testing results

## Project Checklist

Before publishing a new project, confirm:

- `README.md` is complete.
- `REPORT.md` is complete.
- `PROJECT_SUMMARY.md` is complete.
- `REFERENCES.md` is complete.
- `CHECKLIST.md` is complete.
- Screenshots are sanitized.
- PDF export is current.
- Disclaimer wording is included.
- Revision history is updated.
- Changelog is updated.

## Pull Request Format

Use this structure for changes:

```markdown
## Summary

Briefly describe the change.

## Files changed

- File 1
- File 2

## Security review

- No credentials included
- No client data included
- No sensitive screenshots included

## Verification

- Markdown reviewed
- Links checked
- PDF updated when needed
```
