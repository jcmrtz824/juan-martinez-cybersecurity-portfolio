# Project 03 - SOC Incident Investigation

## Portfolio Demonstration - Simulated Incident

Portfolio Demonstration – Simulated Incident

This project is a Portfolio Demonstration. It is a synthetic case study created for a cybersecurity consulting portfolio. It does not represent paid client work, employment history, or testing performed for a real organization unless explicitly stated.

No live third-party systems were tested. No real client names, production IP addresses, credentials, proprietary data, or sensitive information are included.

## Objective

This project demonstrates a full SOC incident investigation and incident response report for a simulated phishing-based compromise against a fictional healthcare organization. The deliverable shows alert triage, email analysis, PowerShell review, Windows event interpretation, MITRE ATT&CK mapping, NIST-aligned response actions, executive risk communication, and recovery recommendations.

## Scope

- Synthetic healthcare environment modeled for portfolio demonstration only
- Simulated phishing email, malicious attachment execution, PowerShell activity, attempted credential theft, and attempted lateral movement
- Simulated SIEM, EDR, email security, and Windows event evidence
- No live testing, no real clients, no real production systems, no credentials, and no real patient data
