# References

Portfolio Demonstration – Simulated Incident

This project is a Portfolio Demonstration. References are included to show the standards, frameworks, and public guidance that support the incident investigation and response approach.

## Notes

- NIST SP 800-61 Rev. 3 supersedes Rev. 2 and was used as the current incident response guidance reference.
- NIST SP 800-61 Rev. 2 is listed because it is historically titled Computer Security Incident Handling Guide and remains commonly referenced in incident response programs.
- MITRE ATT&CK mappings describe simulated attacker behavior in the modeled scenario. They do not confirm activity in a real environment.
- No real client data, production evidence, secrets, or proprietary information are included.
