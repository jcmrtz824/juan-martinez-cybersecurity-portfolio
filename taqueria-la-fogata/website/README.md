# The Website

A complete, working website for Taqueria La Fogata. Mobile-first, loads fast, costs $0 to host.

**You edit one file: [`site-config.js`](./site-config.js).** Everything else runs itself.

---

## What it does

- **Shows whether you're open right now**, calculated from your hours — in *Georgia* time, not the visitor's time zone, so it's right for someone checking from out of state
- **Big tap-to-call button**, stuck to the bottom of the screen on phones
- **One-tap directions** to Google Maps
- **Your full menu**, with prices and a "Popular" tag on your best sellers
- **English / Spanish toggle** — real bilingual support, which almost no small restaurant site has and your market in Kennesaw will use
- **Happy hour and "Coming summer 2027" sections** you can switch on and off
- **Light and dark**, following whatever the visitor's phone is set to, with a manual toggle
- **Structured data for Google**, so your hours and phone can appear directly in search results
- No tracking, no cookie banner, no build step, no dependencies

## Step 1 — Put in your real information

Open `site-config.js` in any text editor. Replace these:

| Line | What to change |
|---|---|
| `phone` | **Your real number.** The 555 one is fake. |
| `address` | **Your real street address.** |
| `mapsUrl` | Search your taqueria on Google Maps → Share → copy the link |
| `hours` | Check all seven days. 24-hour time: `"21:00"` is 9pm. |
| `menu` | Your real dishes and your real prices |
| `social` | Your TikTok link, and Instagram/Google if you have them |

Then change this line:

```js
usingPlaceholders: true,     →     usingPlaceholders: false,
```

That hides the yellow warning banner. **Don't put the site online until you've done this** — the current phone number and address are fake, and sending customers to a fake address is worse than having no website.

### To see it before publishing

Double-click `index.html`. It opens in your browser and works offline. Edit the config, refresh, repeat.

## Step 2 — Put it online free, with GitHub Pages

1. Push this folder to a GitHub repository
2. Repository → **Settings** → **Pages**
3. Source: **Deploy from a branch** → pick your branch → folder `/taqueria-la-fogata/website`
4. Save. In a minute or two you'll have a live URL like
   `https://jcmrtz824.github.io/juan-martinez-cybersecurity-portfolio/taqueria-la-fogata/website/`

### Getting your own domain (worth the $12)

`taquerialafogata.com` looks a lot better than a github.io address, on your sign, on your cups, and on your Google listing.

1. Buy the domain (Namecheap, Cloudflare, Porkbun — about $12/year)
2. Add a file named `CNAME` in this folder containing just your domain:
   ```
   taquerialafogata.com
   ```
3. At your registrar, point DNS at GitHub Pages:
   - Four `A` records for the root: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - One `CNAME` for `www` → `jcmrtz824.github.io`
4. In Settings → Pages, enter the domain and check **Enforce HTTPS**

DNS takes a few hours to a day to settle. HTTPS is free and automatic.

**Other free options if GitHub Pages feels fiddly:** Netlify or Cloudflare Pages — both let you drag this folder into a browser window and get a live link immediately.

## Common edits

**Hide a menu item without deleting it** — add `hidden: true`:
```js
{ name: "Lengua", price: "3.95", hidden: true },
```

**Mark something as a best seller** — add `popular: true`:
```js
{ name: "Birria", price: "3.95", popular: true },
```

**Closed on Mondays:**
```js
mon: { open: null, close: null },
```

**Turn off the 2027 teaser** — in `comingSoon`, set `show: false`.

**Add a new menu category** — copy an existing block in the `menu` array and change it. Order on the page follows order in the file.

**Spanish is optional.** Where you see `{ en: "...", es: "..." }` you can leave out the `es` and it falls back to English. Dish names usually stay in Spanish anyway, so most items just use a plain string.

## If something breaks

**The page is blank.** Almost always a typo in `site-config.js` — a missing comma or quote. Open the browser console (right-click → Inspect → Console) and it'll name the line.

**Hours show wrong.** Use 24-hour time: `"13:00"` not `"1:00"`. And `"21:00"` is 9pm.

**It says closed when you're open.** Check the day keys are spelled `mon tue wed thu fri sat sun`, lowercase.

**Menu changes don't appear.** Hard refresh: Ctrl+Shift+R, or Cmd+Shift+R on a Mac.
